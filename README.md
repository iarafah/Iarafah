### 🧭 What I'm building

**CordaPoint** gives AI teams Arabic data they can inspect: native speakers of each dialect write, review and translate it, and every pass is recorded.

### 🚀 What I've shipped

- **Bilingual company site** in English and Arabic (right-to-left), with per-page SEO, hreflang and a privacy-first consent banner.
- **Recorded interview platform** to vet native dialect speakers, with anonymous reviewers and results kept in a database.
- **Client portal and work tool** for running projects.
- **Talent pipeline** from the website's application forms to a tracked pool with dialect tests.
- **A remote team** of developers and a designer, working through pull requests, code review and automated checks.

### 🛠️ How I work

- I build the product myself every day, using AI-assisted engineering (Claude Code).
- Every change goes through a branch, a pull request, review and checks before it goes live.
- I start from a real need and ship the smallest version that works.
